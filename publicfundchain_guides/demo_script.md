
# Demo Script — 2-minute Walkthrough

## Goal
Show the judges a crisp story: Problem → Solution → Live Demo → Impact.

## Script (approx 2 minutes):
1. **Intro (20s)**: "Funds meant for citizens often vanish. PublicFundChain ensures every rupee is traceable and suspicious transfers are flagged."
2. **Show Dashboard (30s)**: Show Fund Overview, total transactions, alerts. Click an alert to show explanation.
3. **Trigger new transaction (30s)**: Use TransactionForm to send a fund. Show the API call, DB insert, and block recorded in blockchain explorer view.
4. **AI Flagging example (20s)**: Trigger a transaction that violates a rule (e.g., very large amount). Show immediate alert creation.
5. **Human-in-loop (10s)**: Mark a flagged tx as verified (if implemented) and show how it updates model/training set.
6. **Impact + Ask (10s)**: "With minimal infra, governments or auditors can adopt this to build trust."

## Tips
- Rehearse transitions between screens.
- Keep terminal or logs hidden unless they add value.
- Time yourself; demo should be <= 2 minutes.
